# Installation

For this project, Unity 3D will be used as the game engine. For the installation guide, follow the instructions on [Unity Hub Installation Guide](https://docs.unity3d.com/hub/manual/InstallHub.html), the editor version to be used is [6000.2.12f1](https://unity.com/releases/editor/whats-new/6000.2.12f1#notes), since Unity officially announced, the security of previous versions is compromised.
